### Descripción del servicio
Entorno de red en la nube (AWS). Red virtual que permite segmentar y ubicar dispositivos. 
Las VPC se implementan en una de las regiones de AWS y puede alojar recursos de cualquier zona de disponibilidad dentro de esa región.
