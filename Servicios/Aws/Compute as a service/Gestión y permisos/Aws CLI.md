### Descripción del servicio
Command line interface aplicación para aprovisionar y administrar servicios mediante la terminal de un host.
##### Comandos
- Comando para realizar la configuración de la CLI mediante llaves de acceso (key access).
```
$aws configure
```
- Lista todos los usuarios dentro de iam
```
$aws iam list-users
```
