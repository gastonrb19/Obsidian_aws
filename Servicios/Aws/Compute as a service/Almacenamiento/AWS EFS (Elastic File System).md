### Descripción del servicio
Amazon EFS organiza los datos en una estructura jerárquica de carpetas que es familiar para la mayoría de los usuarios, lo que brinda acceso compartido a los archivos en varias instancias o aplicaciones. Esto lo hace especialmente adecuado para los sistemas de administración de contenido, los servidores web y los entornos de desarrollo en los que el acceso tradicional a los sistemas de archivos es necesario.

Amazon Elastic File System (Amazon EFS) es un sistema de archivos fácil de configurar que crece y se reduce automáticamente a medida que se agregan y eliminan archivos. No es necesario aprovisionar ni administrar la capacidad y el rendimiento del almacenamiento. Amazon EFS se puede usar con los servicios de computación y los recursos en las instalaciones de AWS. Puede conectar decenas, cientos e incluso miles de instancias de computación a un sistema de archivos de Amazon EFS al mismo tiempo, y Amazon EFS puede proporcionar un rendimiento uniforme a cada instancia de computación.
Con la interfaz web básica de Amazon EFS, puede crear y configurar sistemas de archivos de inmediato sin ningún costo de configuración mínimo. Solo paga por el almacenamiento que usa y puede elegir entre una variedad de clases de almacenamiento diseñadas para ajustarse a su caso de uso.
