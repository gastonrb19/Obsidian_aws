### Descripción del servicio
Amazon FSx es un servicio completamente administrado que ofrece fiabilidad, seguridad, escalabilidad y un amplio conjunto de capacidades que permiten lanzar, ejecutar y escalar sistemas de archivos de alto rendimiento en la nube de manera práctica y rentable. Con Amazon FSx, puede elegir entre cuatro sistemas de archivos muy utilizados: Lustre, NetApp ONTAP, OpenZFS y Windows File Server. Puede elegir según su familiaridad con un sistema de archivos o según los requisitos de su carga de trabajo en cuanto a conjuntos de características, los perfiles de rendimiento y las capacidades de administración de datos.
#### Amazon FSx para NetApp ONTAP
Es un servicio completamente administrado que combina las características, el rendimiento, las capacidades y las operaciones de API habituales de los sistemas de archivos en las instalaciones de NetApp con la agilidad, la escalabilidad y la sencillez de un servicio de AWS completamente administrado. FSx para ONTAP puede funcionar como sustituto inmediato de las implementaciones de ONTAP existentes, lo que permite a los clientes lanzar y ejecutar los sistemas de archivos de ONTAP en la nube.
FSx para ONTAP ofrece características avanzadas de administración de datos y un almacenamiento flexible de archivos de uso compartido a los que se puede acceder fácilmente desde instancias de computación de Linux, Windows y macOS que se ejecutan en AWS o en las instalaciones.
#### Amazon FSx para OpenZFS
es un servicio de almacenamiento de archivos completamente administrado que lo ayuda a transferir a AWS los datos que residen en servidores de archivos ZFS en las instalaciones u otros servidores de archivos basados en Linux sin cambiar el código de la aplicación ni la forma de administrar los datos. Con FSx para OpenZFS, ya no tiene que preocuparse por configurar y aprovisionar servidores de archivos y volúmenes de almacenamiento. Tampoco tiene que ocuparse de replicar datos, instalar y aplicar parches en el software del servidor de archivos, detectar y solucionar errores de hardware o realizar copias de seguridad de forma manual.
FSx para OpenZFS ofrece un rendimiento líder para cargas de trabajo de archivos pequeños y sensibles a la latencia con las populares capacidades de administración de datos de NAS (instantáneas y clonación), a un precio inferior al de las alternativas con licencia comercial.
#### Amazon FSx para Windows File Server
proporciona servidores de archivos de Microsoft Windows completamente administrados, de alta fiabilidad y escalables, respaldados por un sistema de archivos de Windows integrado. FSx para Windows File Server proporciona un almacenamiento de archivos al que se puede acceder mediante el protocolo de bloque de mensajes del servidor (Service Message Block, SMB) y tiene la capacidad de reemplazar directamente las implementaciones de servidores de archivos de Windows existentes. 
Como servicio completamente administrado, FSx para Windows File Server elimina las tareas administrativas de configuración y aprovisionamiento de servidores de archivos y volúmenes de almacenamiento, y brinda facilidad de uso a los clientes que crean y ejecutan aplicaciones de Windows.
#### Amazon FSx para Lustre
El sistema de archivos Lustre de código abierto está diseñado para aplicaciones que requieren un almacenamiento rápido, en las que usted desea que su almacenamiento esté a la altura de su computación. **Amazon FSx para Lustre** hace que lanzar, ejecutar y escalar sistemas de archivos populares y de alto rendimiento sea conveniente y rentable. Puede vincular los sistemas de archivos FSx para Lustre a los repositorios de datos de Amazon Simple Storage Service (Amazon S3) o a los almacenes de datos en las instalaciones.
FSx para Lustre ofrece los niveles más altos de rendimiento (hasta más de 1 TB/s) e IOPS (millones). Los clientes pueden integrar, acceder y procesar sin problemas sus conjuntos de datos de Amazon S3 mediante el sistema de archivos de alto rendimiento Lustre.
