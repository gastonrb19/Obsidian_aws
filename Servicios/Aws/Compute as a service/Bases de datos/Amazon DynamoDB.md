### Descripción del servicio
DynamoDB es una base de datos NoSQL completamente administrada que proporciona un rendimiento rápido y uniforme a cualquier escala. Cuenta con un modelo de facturación flexible, una estrecha integración con la infraestructura como código (IaC) y un modelo operativo sin intervención. DynamoDB se convirtió en la base de datos preferida para dos categorías de aplicaciones: aplicaciones de gran escala y aplicaciones sin servidor. Aunque DynamoDB es la base de datos preferida para aplicaciones de gran escala y sin servidor, puede funcionar para casi todas las cargas de trabajo de aplicaciones de procesamiento de transacciones en línea (OLTP).

DynamoDB es un servicio de base de datos NoSQL completamente administrado que ofrece un rendimiento rápido y predecible con perfecta escalabilidad. Mediante DynamoDB, puede descargar la carga administrativa de operar y escalar una base de datos distribuida No necesita preocuparse por el aprovisionamiento, la instalación y la configuración de hardware, la replicación, la aplicación de parches de software ni el escalado de clústeres.

Con DynamoDB, puede hacer lo siguiente:

- Crear tablas de bases de datos que puedan almacenar y recuperar cualquier cantidad de datos, así como satisfacer cualquier nivel de tráfico de solicitudes. 
- Escalar o reducir verticalmente la capacidad de rendimiento de sus tablas sin tiempo de inactividad ni degradación del rendimiento. 
- Supervisar el uso de los recursos y las métricas de rendimiento mediante la consola de administración de AWS.

DynamoDB distribuye automáticamente los datos y el tráfico de las tablas entre un número suficiente de servidores para satisfacer sus requisitos de almacenamiento y rendimiento, al mismo tiempo que mantiene un rendimiento uniforme y rápido. Todos los datos se almacenan en SSD y se replican automáticamente en varias zonas de disponibilidad de una región, lo que proporciona una alta disponibilidad y durabilidad de datos.

### Componentes principales de DynamoDB
En DynamoDB se trabaja principalmente con tablas, elementos y atributos. Una tabla es un conjunto de elementos y cada elemento es un conjunto de atributos. DynamoDB utiliza claves primarias para identificar únicamente cada elemento en una tabla e índices secundarios a fin de brindar más flexibilidad de consulta.
