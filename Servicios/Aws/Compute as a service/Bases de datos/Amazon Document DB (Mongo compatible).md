### Descripción del servicio
Amazon DocumentDB es una base de datos de documentos completamente administrada de AWS. Una base de datos de documentos es un tipo de base de datos NoSQL que puede usar para almacenar y consultar documentos complejos en su aplicación. Estos tipos de bases de datos funcionan bien en los siguientes casos de uso: sistemas de administración de contenido, administración de perfiles y aplicaciones web y móviles. Amazon DocumentDB tiene compatibilidad de API con MongoDB. Esto significa que puede usar bibliotecas populares de código abierto para interactuar con Amazon DocumentDB o puede migrar las bases de datos existentes a Amazon DocumentDB con mínima dificultad.
