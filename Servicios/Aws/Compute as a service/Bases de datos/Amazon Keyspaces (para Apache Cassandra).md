### Descripción del servicio
Amazon Keyspaces es un servicio de base de datos escalable, de alta disponibilidad, administrado y compatible con Apache Cassandra. Apache Cassandra es una opción popular para aplicaciones de gran escala que requieren un rendimiento de primer nivel. Amazon Keyspaces es una buena opción para aplicaciones de gran volumen con patrones de acceso sencillos. Con Amazon Keyspaces puede ejecutar sus cargas de trabajo de Cassandra en AWS con el mismo lenguaje de consulta de Cassandra (Cassandra Query Language, CQL), los controladores con licencia Apache 2.0 y las herramientas que utiliza actualmente.
