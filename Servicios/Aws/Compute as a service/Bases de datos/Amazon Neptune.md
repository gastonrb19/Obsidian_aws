### Descripción del servicio
Neptune es un servicio de base de datos de gráficos completamente administrado que AWS ofrece. Una base de datos de gráficos es una buena opción para los datos de alta conexión con una amplia variedad de relaciones. Las empresas suelen utilizar bases de datos de gráficos para motores de recomendación, detección de fraude y gráficos de conocimiento.
