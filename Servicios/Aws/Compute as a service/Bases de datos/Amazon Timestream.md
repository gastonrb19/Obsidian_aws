### Descripción del servicio
Timestream es un servicio de base de datos de serie temporal rápido, escalable y sin servidor para internet de las cosas (IoT) y aplicaciones operativas. Facilita el almacenamiento y análisis de billones de eventos por día hasta 1000 veces más rápido y por tan solo una décima parte del costo de las bases de datos relacionales. Los datos de serie temporal son una secuencia de puntos de datos registrados durante un intervalo de tiempo. Se usan para medir eventos que cambian con el paso del tiempo, como los precios de las acciones o las mediciones de temperatura.
