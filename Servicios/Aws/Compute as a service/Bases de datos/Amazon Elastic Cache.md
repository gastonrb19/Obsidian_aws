### Descripción del servicio
ElastiCache es una solución de almacenamiento en caché en memoria completamente administrado. Admite dos motores de caché en memoria de código abierto: Redis y Memcached. En este caso, usted no es responsable de las conmutaciones por error, las copias de seguridad y restauraciones, ni las actualizaciones de software de las instancias.
