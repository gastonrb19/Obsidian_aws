### Descripción del servicio
MemoryDB es un servicio de base de datos en memoria duradero y compatible con Redis que ofrece un rendimiento ultrarrápido. Con MemoryDB, puede lograr una latencia de lectura en microsegundos, una latencia de escritura en milisegundos de un solo dígito, alto rendimiento y durabilidad Multi-AZ para aplicaciones modernas, como aquellas que cuentan con una arquitectura de microservicios. Puede usar MemoryDB como una base de datos primaria y completamente administrada para crear aplicaciones de alto rendimiento. No necesita administrar por separado una caché, una base de datos duradera o la infraestructura subyacente requerida.
